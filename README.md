# 🏝️ АРХИПЕЛАГ КОДА (Archipelago of Code)
> **Enterprise Interactive Coding & Computer Science Education Platform**  
> Повноцінна інноваційна освітня екосистема для опанування програмування від базових концепцій до високорівневої архітектури.

---

## 🌟 Огляд платформи (Overview)

**«АРХИПЕЛАГ КОДА»** — це інтерактивна платформа нового покоління для вивчення програмування, комп'ютерних наук та системної інженерії. Платформа перетворює процес навчання на дослідження цифрового архіпелагу, де кожен острів представляє окремий технологічний напрямок або фундаментальну концепцію.

Платформа підходить для **шкіл**, **коледжів**, **професійно-технічних закладів** та **університетів**, підтримує гнучкі рівні складності та адаптується під освітній профіль студента.

---

## ✨ Ключові можливості (Features)

### 1. 🗺️ 3D та 2D Інтерактивна карта Архіпелагу
- **Тривимірний світ знань (Three.js)** з плавною орбітальною камерою, процедурними біомами, маяками прогресу та динамічним освітленням.
- **Доступний 2D-режим (Accessible Topology)** для швидкої навігації, підтримки screen reader та роботи на пристроях із низькою продуктивністю.
- **Острови Архіпелагу**:
  - 🟢 **Острів Нуль (Zero Island)** — Основи логіки, пам'ять, змінні, цикли та перша програма.
  - 🐍 **Зміїна Долина (Python Isle)** — Синтаксис, структури даних, функції, автоматизація.
  - ⚡ **Вулкан Скриптів (JavaScript Oasis)** — Події, об'єкти, асинхронність, DOM.
  - 🗄️ **Реляційний Атол (SQL Citadel)** — Бази даних, запити SELECT, JOIN, агрегація, оптимізація.
  - 🧩 **Пік Алгоритмів (Algo Mountain)** — Складність Big-O, рекурсія, сортування, структури даних.
  - 🛡️ **Фортеця Безпеки (Security Keep)** — Санітизація, захист від SQLi та XSS, криптографія.
  - 🐧 **Ядро Системи (Linux & Systems)** — Процеси, потоки, термінал, системні виклики.

### 2. 💻 Професійне IDE з плаваючими вікнами (Window Management)
- **Вільне переміщення вікон (Draggable Windows):**
  - **Плаваюче вікно консолі (Floating Console):** консоль та результати тестів можна перетворити на окреме плаваюче вікно, вільно перетягувати мишкою за заголовок у будь-яку частину екрана та масштабувати за правий нижній кут.
  - **Інтерактивні сплітери (Splitters):** можливість плавно регулювати ширину панелі завдань, висоту або ширину консолі простим перетягуванням межі.
  - **Пресетні розкладки:** перемикання в 1 клік між «3 Колонки», «Консоль знизу» та «Плаваючі вікна».
  - **Керування вікнами:** мінімізація в нижній трей, розгортання на весь екран, закріплення праворуч або знизу.
- **Багатофайловий редактор:** робота з `main`, `utils`, автоматичними тестами та `README.md`.
- **Вбудована ізольована пісочниця (Isolated Sandbox Engine):** миттєве виконання коду та автоматична перевірка тест-кейсів.
- **Система Oracle Hints:** 3-рівневі адаптивні підказки (Концепт → Псевдокод → Повний розв'язок).

### 3. 🧠 Інтелектуальний AI Наставник (AI Mentor)
- Постійно доступний плаваючий віджет **«AI Наставник онлайн»** у правому нижньому кутку.
- Підтримка вільного переміщуваного вікна AI помічника поруч із кодом.
- **Швидкі інструменти:**
  - 💬 Пояснення складних концепцій простою мовою.
  - 🔍 Комплексне Код-Рев'ю (Clean Code, стандарти якості, потенційні баги).
  - ⏱️ Автоматична оцінка часової та просторової складності алгоритму (Big-O).

### 4. 🧪 Практичний хаб симуляторів (Labs Hub)
- **Virtual Linux Terminal:** емуляція шеллу з файловою системою, командами `ls`, `cat`, `grep`, `mkdir`, `top`.
- **SQL Interactive Studio:** виконання запитів, візуалізація таблиць і фільтрація результатів.
- **Visual Git & Merge Lab:** наочний граф комітів, симуляція конфліктів злиття та розв'язання merge conflicts.
- **Memory Inspector & Step Debugger:** покроковий дебаггер зі стеком викликів, локальними змінними та точками зупинки (breakpoints).
- **Robot Algorithm Simulator:** управління автономним роботом за допомогою циклів та умов на сітці з перешкодами.

### 5. 📊 Академічний моніторинг & Прогрес
- Інтерактивна панель **«Мій Прогрес & Досягнення»**:
  - Відстеження досвіду (XP) та шкала до наступного рівня.
  - Статистика виконаних завдань і відсоток опанування кожного острова.
  - Ударний режим (Daily Streak 🔥).
  - Індекс цілісності коду (Integrity Score 🛡️).
- **Рольовий доступ (RBAC):**
  - **Студент:** проходження уроків, лабораторій, проєктів та кар'єрних треків.
  - **Викладач (Teacher Portal):** журнал успішності, керування групами, статистика завдань.
  - **Адміністратор (Admin Portal):** аналітика системи, моніторинг навантаження, керування контентом.

## 🚀 Встановлення та запуск (Getting Started)

### Попередні вимоги
- Node.js версії `>= 20.0.0`
- Менеджер пакетів `npm` або `bun`

### Кроки запуску

1. **Клонувати репозиторій:**
   \`\`\`bash
   git clone https://github.com/lilaveanivest20-cloud/-.git
   cd -
   \`\`\`

2. **Встановити залежності:**
   \`\`\`bash
   npm install
   \`\`\`

3. **Налаштувати змінні оточення:**
   Створіть файл `.env` на основі `.env.example`:
   \`\`\`bash
   cp .env.example .env
   \`\`\`
   *(Опціонально) додайте `GEMINI_API_KEY` для активації хмарних запитів AI Наставника. За замовчуванням працює вбудований офлайн-наставник.*

4. **Запустити сервер розробки:**
   \`\`\`bash
   npm run dev
   \`\`\`
   Додаток буде доступний за адресою: `http://localhost:3000`

5. **Збірка для продакшену (Production Build):**
   \`\`\`bash
   npm run build
   npm start
   \`\`\`
